# 釣魚連結與帳號安全

[首頁](index.md) · [基本概念](basic-concepts.md) · [詐騙類型](scam-types.md) · [詐騙話術](scam-tactics.md) · [辨識方法](scam-detection.md) · [受害處理](victim-response.md)

本頁整理釣魚連結、假網站、假冒機構及 LINE 帳號遭盜用後可能出現的情境。內容依照官方資料整理，並區分官方資料的原始資訊與 AI 協助分類。

釣魚連結或帳號盜用只是資料所記載的詐騙方式之一，不代表所有連結、網站、物流流程或 LINE 訊息都涉及詐騙。

---

## 1. 釣魚連結的基本概念

釣魚連結是資料中描述的一種詐騙手法：詐騙者透過電子郵件、簡訊或其他訊息，假冒民眾熟悉的機構，引導民眾點擊連結、進入仿冒網站或聯繫假客服。

來源記載的假冒機構包括政府機關、電信公司、金融機構、電商平台及物流業者。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

### 為什麼不能只看網站外觀判斷真偽

來源提到網路購物詐騙會結合偽冒物流平台及釣魚連結。仿冒網站可能具有類似一般交易流程或熟悉的機構名稱，因此不能只因網站外觀熟悉，就認定它是真正的官方平台。[SRC-005](../raw/SRC-005.md)

對可疑連結，更應配合官方 App、手動搜尋官方網站或官方客服等管道查證。[SRC-004](../raw/SRC-004.md)

## 2. 假冒機構與釣魚訊息

### 可能假冒的機構

來源記載，詐騙者可能假冒以下機構：

| 假冒類型 | 來源內容 |
|---|---|
| 政府機關 | 假冒政府機關傳送通知或連結；釣魚連結也可能假冒政府機關。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |
| 電信公司 | 可利用電信費欠繳等理由傳送通知。[SRC-004](../raw/SRC-004.md) |
| 金融機構 | 可假冒銀行或金融機構，提出帳戶驗證、付款或系統異常等理由。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |
| 電商平台 | 可假冒電商平台或網購流程。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |
| 物流業者 | 可假冒物流業者，提供疑似物流連結或配送問題通知。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |

### 常見誘導理由

來源記載的常見理由包括：

- 發票中獎
- 訂單異常
- 積分或點數即將到期
- 停車費未繳
- 電信費欠繳
- 付款失敗
- 帳戶驗證異常
- 中獎通知
- 配送問題
- 帳戶或交易異常

這些理由可能被詐騙者用來誘導民眾點擊連結或產生後續操作。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

### 官方資料的整理方式

來源中提到的機構及誘導理由是常見手法，不代表任何收到此類內容的民眾都一定遭遇詐騙，也不代表相同理由一定都是由詐騙者發出。

判斷時應依實際訊息、連結及要求的操作，並透過官方管道重新確認。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

## 3. 偽冒物流平台與假網站

### 網路購物吸引民眾的方式

來源描述詐騙者可能先在 Facebook、Threads 等社群平台刊登：

- 低價商品
- 免費贈送商品
- 假買家留言

再引導有興趣的民眾轉到 LINE 或 Messenger 私訊洽談。[SRC-005](../raw/SRC-005.md)

此描述僅表示其中一種網購詐騙情境，不代表所有社群商品、低價商品或免費贈送都涉及詐騙。[SRC-005](../raw/SRC-005.md)

### 偽冒物流連結

詐騙者可能提供偽冒物流業者的釣魚連結。來源列出的例子包括：

- 7-11 賣貨便
- 全家 Fun 心取
- 黑貓宅急便
