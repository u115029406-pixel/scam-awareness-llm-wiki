# 詐騙訊息辨識方法

[首頁](index.md) · [基本概念](basic-concepts.md) · [詐騙類型](scam-types.md) · [釣魚與帳號安全](phishing-security.md) · [詐騙話術](scam-tactics.md) · [受害處理](victim-response.md)

本頁整理辨識可疑電話、簡訊、連結、網購訊息及金融操作要求的方法。

下列檢查事項來自來源記載的案例及官方防詐建議。可疑線索不等於單獨證明詐騙；若情況符合多項警訊，或無法透過官方管道獨立查證，應暫停操作並另行確認。

## 1. 可疑電話辨識

[主要來源：SRC-003](../raw/SRC-003.md) 與 [SRC-006](../raw/SRC-006.md)

### 值得提高警覺的特徵

來源列出的可疑電話特徵包括：

- 陌生來電。
- 開頭帶有「+」的境外來電。
- 來電者以交易設定錯誤或重複扣款為由聯絡民眾。
- 來電者聲稱系統出錯、升級 VIP 會員或帳戶需要處理。
- 來電者要求操作 ATM、網路銀行或購買遊戲點數。
- 來電者能說出交易明細，但要求進行金融操作或讓民眾相信身分。

即使對方能說出交易明細，也不能只因此直接相信來電者的身分。[SRC-003](../raw/SRC-003.md)

### 不應直接相信的情況

遇到陌生來電者聲稱自己是商家、基金會、銀行或政府機關人員時，不能只因對方的身分說法就直接相信。來源建議應掛斷電話，再自行查詢官方客服或透過官方管道確認。[SRC-003](../raw/SRC-003.md) [SRC-006](../raw/SRC-006.md)

來源也指出，ATM 只有提款及轉帳功能，不能用來解除分期付款或退款；遊戲點數也不能用來解除交易設定或進行身分識別。因此，來電要求操作這些項目來解除問題時，應立即停止並查證。[SRC-003](../raw/SRC-003.md)

### 正確處理方式

遇到可疑電話時：

1. 不急著依照對方指示操作。
2. 不因對方催促而慌張。
3. 掛斷可疑電話。
4. 自行查詢商家、銀行或機關的官方客服。
5. 撥打 165 反詐騙諮詢專線查證。
6. 必要時撥打 110 或前往警察機關尋求協助。[SRC-003](../raw/SRC-003.md) [SRC-006](../raw/SRC-006.md)

### 注意事項

陌生來電或境外來電應提高警覺，不表示所有陌生電話或帶「+」的境外電話都是詐騙；判斷仍應依照實際內容及操作要求。[SRC-003](../raw/SRC-003.md)

## 2. 可疑簡訊與釣魚連結辨識

[主要來源：SRC-004](../raw/SRC-004.md) 與 [SRC-005](../raw/SRC-005.md)

### 常見誘導理由

來源記載，詐騙簡訊或連結可能使用以下理由：

- 發票中獎
- 訂單異常
- 積分或點數即將到期
- 停車費未繳
- 電信費欠繳
- 付款失敗
- 帳戶驗證異常
- 配送問題
- 帳戶異常

這些理由可能被用來誘導民眾點擊連結、進入仿冒網站或聯繫假客服。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

### 可能假冒的機構

來源記載，詐騙者可能假冒：

| 機構類型 | 可疑情境 |
|---|---|
| 政府機關 | 假冒政府機關傳送中獎、欠費或帳戶異常訊息。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |
| 電信公司 | 使用電信費欠繳、帳戶驗證或付費異常理由。[SRC-004](../raw/SRC-004.md) |
| 金融機構 | 假冒銀行專員或金融機構，聲稱帳戶、金流或身分驗證異常。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |
| 電商平台 | 假冒電商平台，以訂單異常、付款失敗或中獎等理由聯繫。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |
| 物流業者 | 假冒物流平台或配送通知，提供疑似物流的釣魚連結。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |

### 連結後可能出現的情況

民眾點擊不明連結後，可能：

- 被引導加入 LINE 線上客服。
- 被假客服要求操作網路銀行、ATM、無卡提款或掃描 QR Code。
- 進入仿冒網站並被要求輸入個人資料、信用卡資訊或 OTP。
- 看到實名認證失敗、金流驗證失敗或帳號凍結等訊息。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

### 不應只看外觀或品牌名稱

來源提醒，不能只因網站外觀熟悉或訊息中有機構名稱，就認定內容是真實官方平台。應透過官方 App、手動搜尋官方網站或官方客服管道重新確認。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

單一誘導理由或假冒名稱不一定能單獨證明詐騙，但若連結要求操作金融服務、提供敏感資料或使用陌生客服，應提高警覺。
