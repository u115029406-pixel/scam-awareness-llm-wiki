## 1. 假冒身分

詐騙者可能利用民眾熟悉的機構或人物來提高可信度。

### 假冒商家、基金會或銀行人員

來源描述詐騙者可能取得交易紀錄及個人資料，然後假冒商家、基金會或銀行人員聯絡民眾。[SRC-003](../raw/SRC-003.md)

### 假冒政府、電信、金融及物流機構

來源記載，詐騙者可能透過訊息或連結假冒政府機關、電信公司、金融機構、電商平台及物流業者。常見目的包括引導民眾點擊連結、進入仿冒網站或聯繫假客服。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

來源也記載假冒物流業者的例子，包括 7-11 賣貨便、全家 Fun 心取、黑貓宅急便、新竹物流及順豐。[SRC-005](../raw/SRC-005.md)

### 假冒 LINE 帳號持有人

詐騙者可能盜用或冒用他人的 LINE 帳號，再假裝原帳號持有人向好友借錢或傳送詐騙連結。[SRC-004](../raw/SRC-004.md)

即使訊息來自熟悉親友的帳號，來源仍建議向本人另外查證。[SRC-004](../raw/SRC-004.md)

## 2. 常見詐騙話術

下列話術依來源記載分類。這些說法是需要提高警覺的例子，不代表每次出現都一定是詐騙。

### 交易異常類

來源記載的交易異常說法包括：

| 話術 | 來源情境 |
|---|---|
| 交易設定錯誤 | 詐騙者聲稱交易設定錯誤，並要求民眾操作金融服務。[SRC-003](../raw/SRC-003.md) |
| 帳戶將重複扣款 | 詐騙者聲稱帳戶將被重複扣款，再要求民眾操作 ATM、網路銀行或購買遊戲點數。[SRC-003](../raw/SRC-003.md) |
| 帳戶設定錯誤 | 詐騙者可能以解除錯誤設定或取消重複扣款為理由，引導民眾操作。[SRC-004](../raw/SRC-004.md) |
| 訂單異常 | 訊息可能聲稱訂單異常或訂單即將失效，藉此誘導民眾點擊連結。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |
| 付款失敗 | 訊息可能聲稱付款失敗，誘導民眾進入連結或仿冒網站。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md) |

### 帳戶驗證類

來源記載，假網站或假客服可能以以下說法引導民眾：

- 未完成實名認證
- 金流驗證失敗
- 帳號遭凍結
- 帳戶認證異常
- 需要身分驗證
- 帳戶驗證異常

假網站可能藉此引導民眾聯繫所謂的線上客服，再要求進行金融操作。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

### 通知誘導類

來源記載的通知類話術包括：

- 發票中獎
- 訂單異常
- 積分或點數即將到期
- 停車費未繳
- 電信費欠繳
- 中獎通知
- 配送問題
- 帳戶或付款異常

這些說法可能被用來誘導民眾點擊不明連結或進入仿冒網站。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

來源並未提供足以證明這些話術一定會使民眾產生特定心理反應的研究，因此本頁不將恐懼、急迫感或信任寫成已證實的心理學定律。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)

### 社群誘導類

來源記載，詐騙者可能在 Facebook、Threads 等社群平台使用：

- 低價商品
- 免費贈送商品
- 假買家留言
- 投票
- 抽獎活動
- 協助帳號設定

網購詐騙可能以商品或贈送吸引民眾，再引導其從社群平台轉到 LINE 或 Messenger 私訊。[SRC-005](../raw/SRC-005.md)

LINE 帳號盜用也可能以投票、抽獎或協助帳號設定為由取得帳號。[SRC-004](../raw/SRC-004.md)

這些說法只是來源記載的案例，不代表所有低價商品、抽獎、投票或社群私訊都涉及詐騙。[SRC-004](../raw/SRC-004.md) [SRC-005](../raw/SRC-005.md)
